# Payroll Vibes

Upload a payroll spreadsheet and let Claude find the errors. The app ingests `.xls`/`.xlsx` files, runs Claude with code execution to analyze the data, and presents a report of what it found. You can then ask follow-up questions in a chat interface.

## Tech Stack

- **Backend:** FastAPI + Uvicorn
- **AI:** Anthropic Claude API (Files API + Code Execution beta)
- **Frontend:** Vanilla HTML/CSS/JS

## Quick Start

**Prerequisites:** Python 3.11+, [uv](https://docs.astral.sh/uv/), an [Anthropic API key](https://console.anthropic.com/)

```bash
# Clone and enter the project
git clone https://github.com/theholymath/payroll-vibes.git
cd payroll-vibes

# Set up environment
cp .env.example .env
# Edit .env and add your ANTHROPIC_API_KEY

# Install dependencies and run
uv sync
uv run uvicorn app.main:app --reload
```

Open http://localhost:8000, upload a spreadsheet, and start chatting.

## Configuration

Set these in `.env`:

| Variable | Default | Description |
|---|---|---|
| `ANTHROPIC_API_KEY` | *(required)* | Your Anthropic API key |
| `CLAUDE_MODEL` | `claude-sonnet-4-5-20250929` | Claude model to use |
| `MAX_TOKENS` | `16384` | Max tokens per response |

## Test Spreadsheet

`payroll_test_errors.xlsx` is a purpose-built spreadsheet containing 9 intentional errors for validating the auditing app. Upload it and confirm Claude flags each one.

| # | Error Type | Details | Expected Finding |
|---|---|---|---|
| 1 | Sum mismatch | TOTAL row shows $64,922; actual sum is $59,922 | Total is $5,000 higher than the sum of employee rows |
| 2 | Duplicate employee | Anne Nelson (ID 1) appears twice | Identical row for employee 1 |
| 3 | Negative gross pay | Tom Baker has -$630 gross pay | Negative pay amount flagged |
| 4 | Outlier hourly rate | Sarah Lee at $1,200/hr | Rate far outside the $7.25–$500 reasonable range |
| 5 | Excessive hours | Kevin Moore worked 168 hrs/week | Hours exceed a reasonable weekly maximum |
| 6 | Tax rate >50% | Diana Price: $624 tax on $1,040 gross (60%) | Tax deduction percentage is unreasonably high |
| 7 | Net pay mismatch | Brian Hall: $960 - $96 = $864, but net shows $664 | Net pay doesn't equal gross minus deductions |
| 8 | Missing values | Pat's row has blank last name, gender, department, rate, hours | Row contains empty required fields |
| 9 | #REF! error string | "Error Row" has `#REF!` in the gross_pay cell | Spreadsheet error value instead of a number |

The file was generated by `generate_test_errors.py` (run once, safe to delete).
